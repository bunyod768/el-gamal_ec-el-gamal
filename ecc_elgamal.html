📐 Nazariy Asoslar
Egri chiziq tenglamasi: y² ≡ x³ + ax + b (mod p), Δ = −16(4a³ + 27b²) ≢ 0 (mod p)
Nuqta qo'shish (P ≠ Q): λ = (y₂−y₁)·(x₂−x₁)⁻¹ mod p x₃ = λ²−x₁−x₂ mod p, y₃ = λ(x₁−x₃)−y₁ mod p
Ikkilash (P = Q, 2P): λ = (3x₁²+a)·(2y₁)⁻¹ mod p
Generator tartib n — avtomatik brute-force: n = min{ k ∈ ℤ⁺ : k·G = O } (Hasse: p+1−2√p ≤ n ≤ p+1+2√p)
ElGamal protokoli: KeyGen : d ← rand[1, n−1], Q = d·G Enc : C₁ = k·G, C₂ = m + Hx(k·Q) mod p Dec : S = d·C₁, m = C₂ − Hx(S) mod p
